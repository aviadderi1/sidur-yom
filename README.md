# סידור יום – Android

1. צור ריפו חדש ב-GitHub (למשל `sidur-yom`) והעלה את כל הקבצים כאן (כולל תיקיית `.github`).
2. Actions ← Build APK ← Run workflow (או פשוט push ל-main).
3. אחרי כ-3 דקות: Releases ← `sidur-yom.apk` ← הורד לטלפון והתקן.

הקובץ `app/src/main/assets/index.html` הוא האפליקציה עצמה – כל עדכון בו + push = APK חדש.
